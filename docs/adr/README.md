# 架构决策记录（ADR）

这里是 FerroOCR 的关键决策记录。每条 ADR 说明**当时面对什么约束、考虑过什么方案、为什么选了这个、选完之后接受了什么代价**。

ADR 只记「已定的事」，不记待办。改动一条既有决策的正确方式是新增一条 ADR 并在其中声明「取代 ADR-XXX」，而不是回头编辑旧文件——决策的历史本身是资产。

| 编号 | 决策 | 状态 |
|---|---|---|
| [ADR-001](ADR-001-传输层四级接入阶梯.md) | 传输层从 Named Pipe 单通道改为四级接入阶梯（L0/L1/L2/L3） | 已采纳 |
| [ADR-002](ADR-002-l2-http-默认开启与单包.md) | L2 HTTP 默认开启，且只出一个包，行为差异用启动参数表达 | 已采纳 |
| [ADR-003](ADR-003-双引擎与-DirectML.md) | GPU 走 ONNX Runtime + DirectML 双引擎，不自研 CUDA 后端 | 已采纳 |
| [ADR-004](ADR-004-不做截屏识别.md) | 不做截屏 / 屏幕区域识别，只接受传入图片 | 已采纳 |
| [ADR-005](ADR-005-代码签名非阻塞.md) | 代码签名证书降级为非阻塞项，分发路径优先 | 已采纳 |
